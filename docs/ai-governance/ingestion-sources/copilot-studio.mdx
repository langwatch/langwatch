<Warning>
**This source type is retired.** It polled Microsoft's directory audit, the log
of who was made an administrator and which app was granted consent. That log
records changes to the directory; it has never contained a Copilot conversation
and no configuration would make it.

Copilot Studio conversations are read from Dataverse instead.
See [Microsoft Copilot Studio (Dataverse)](/ai-governance/ingestion-sources/copilot-studio-dataverse).
</Warning>

## What happened

The `copilot_studio` source type was created as a setup contract for a planned
Purview Audit poller. The poller was never built because the underlying API
(`graph.microsoft.com/v1.0/auditLogs/directoryAudits`) does not carry
conversation data, only directory-level changes like admin consent grants and
app registrations.

The replacement, `copilot_studio_dataverse`, reads conversations directly from
the Power Platform environment's Dataverse transcript table, which is where
Copilot Studio agents actually store what was said.

## For existing sources configured on this type

Sources already configured as `copilot_studio` still appear in the inventory
and still resolve their adapter on a scheduled run. They will not produce
conversation data because the underlying API has none to offer.

To start reading conversations, create a new source of type
`copilot_studio_dataverse` pointed at the same Power Platform environment.
The old source can then be disabled.

## The old type is no longer offered

The source picker no longer shows `copilot_studio` as an option for new sources.
Only `copilot_studio_dataverse` is offered.
