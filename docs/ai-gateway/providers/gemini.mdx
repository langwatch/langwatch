## Add the credential

Open **Settings > Model Providers**, click **Add Model Provider** and select **Gemini**. Give the row a name, pick the organization, team or project it belongs to, and fill in:

| Field | Value |
|---|---|
| `GEMINI_API_KEY` | A Google AI Studio API key, or a Google Cloud API key when you set a project. |
| `GEMINI_PROJECT` | Optional. The Google Cloud project of a Gemini Enterprise Agent Platform key. With the location set, the row calls `aiplatform.googleapis.com` instead of AI Studio. |
| `GEMINI_LOCATION` | Optional. The location for the project, for example `us-central1`. Set both or neither. |

Save the row. Every virtual key whose scope can see the row can now dispatch to it, unless the key restricts its providers. See [Virtual keys](/ai-gateway/virtual-keys#create-a-virtual-key).

## Model names

Write `gemini/<model>`, for example `gemini/gemini-2.5-flash`. A bare name that starts with `gemini-` resolves to Gemini when the key reaches a Gemini row.

## Send a request

```bash
curl https://gateway.langwatch.ai/v1/chat/completions \
  -H "Authorization: Bearer $LANGWATCH_VIRTUAL_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini/gemini-2.5-flash",
    "messages": [{"role": "user", "content": "Say hi in one word"}]
  }'
```

## Google GenAI SDKs

The Google GenAI SDKs call `/v1beta/*`. Point them at the gateway host and send the virtual key as the API key. The SDK puts it in the `X-Goog-Api-Key` header, which the gateway accepts.

```python
from google import genai

client = genai.Client(
    api_key="vk-lw-...",
    http_options={"base_url": "https://gateway.langwatch.ai"},
)
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Say hi in one word",
)
print(response.text)
```

## Endpoints

| Endpoint | Served |
|---|---|
| `POST /v1/chat/completions` | Yes |
| `POST /v1/messages` | Yes, translated |
| `POST /v1/embeddings` | Yes |
| `/v1beta/*` | Yes, forwarded to the Gemini API |
| `GET /v1/models` | Yes, from the Gemini catalog |
