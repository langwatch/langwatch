## What it is

The management REST API creates and edits the gateway's own resources: virtual keys, budgets, cache rules, and the spend they produce. It is the surface the `langwatch` CLI and the LangWatch dashboard use.

It runs on the LangWatch control plane, not on the gateway data plane:

```
https://app.langwatch.ai/api/gateway/v1
```

Self-hosted: use your own control plane host with the same path prefix.

## Authentication

Send a LangWatch API key on every request:

```
Authorization: Bearer $LANGWATCH_API_KEY
```

`X-Auth-Token` is accepted in its place. Virtual keys, budgets and cache rules authenticate with a project API key. Spend authenticates with an organization API key.

## Permissions

Each resource needs its own permission on the key:

| Resource | Read | Write |
|---|---|---|
| Virtual keys | `virtualKeys:view` | `virtualKeys:create`, `virtualKeys:update`, `virtualKeys:rotate`, `virtualKeys:delete` |
| Budgets | `gatewayBudgets:view` | `gatewayBudgets:create`, `gatewayBudgets:update`, `gatewayBudgets:delete` |
| Cache rules | `gatewayCacheRules:view` | `gatewayCacheRules:create`, `gatewayCacheRules:update`, `gatewayCacheRules:delete` |
| Spend | `gatewaySpend:view` | `gatewaySpend:manage` |

A legacy project key passes every check. A scoped API key is checked against its role bindings.
