## Usage

<Info>
  The LangWatch API key is configured by default via the `LANGWATCH_API_KEY` environment variable.
</Info>

Set up observability and register the OpenTelemetry integration for the Vercel AI SDK (AI SDK 7):

```typescript
import { setupObservability } from "langwatch/observability/node";
import { generateText, registerTelemetry } from "ai";
import { OpenTelemetry } from "@ai-sdk/otel";
import { openai } from "@ai-sdk/openai";

setupObservability({ serviceName: "<project_name>" });
registerTelemetry(new OpenTelemetry({ runtimeContext: true }));

async function main(message: string): Promise<string> {
  const response = await generateText({
    model: openai("gpt-5-mini"),
    instructions: "You are a witty assistant.",
    prompt: message,
  });
  return response.text;
}

console.log(await main("Hey, tell me a joke"));
```

Once `registerTelemetry` has run, every `generateText` and `streamText` call reports to LangWatch, with no flag to set per call. `instructions` is the AI SDK 7 name for the system prompt. `runtimeContext: true` lets you attach metadata to a call (see [Metadata](#metadata)). For Next.js applications, configure OpenTelemetry in your `instrumentation.ts` file using `LangWatchExporter`.

### AI SDK 6 and earlier

There is no `registerTelemetry` before AI SDK 7. Enable telemetry on each call with `experimental_telemetry` instead, and use `system` for the system prompt:

```typescript
import { setupObservability } from "langwatch/observability/node";
import { generateText } from "ai";
import { openai } from "@ai-sdk/openai";

setupObservability({ serviceName: "<project_name>" });

const response = await generateText({
  model: openai("gpt-5-mini"),
  system: "You are a witty assistant.",
  prompt: "Hey, tell me a joke",
  experimental_telemetry: { isEnabled: true },
});
```

<Note>
  AI SDK 7 emits no spans until an integration is registered, so an AI SDK 6 snippet left
  unchanged after upgrading to AI SDK 7 sends LangWatch no traces. Add the `registerTelemetry` call
  shown above when you upgrade.
</Note>

## Metadata

LangWatch reads these keys from the metadata you attach to a call:

| Key           | What it does                                                                      |
| ------------- | --------------------------------------------------------------------------------- |
| `labels`      | An array of labels. Filter the trace list by them.                                |
| `thread_id`   | Groups the call into a conversation with every other call that sends the same id. |
| `user_id`     | The end user the call belongs to.                                                 |
| `customer_id` | The customer or tenant the call belongs to.                                       |

Any other key becomes custom metadata on the trace, filterable by its own name.

### AI SDK 7: runtime context

Pass `runtimeContext` to the call and list the keys you want on the spans in
`telemetry.includeRuntimeContext`. The integration must be registered with
`runtimeContext: true`, as in the setup above; it is off by default.

```typescript
const response = await generateText({
  model: openai("gpt-5-mini"),
  prompt: message,
  runtimeContext: {
    labels: ["checkout", "beta"],
    thread_id: "conversation-8f21",
    user_id: "user-42",
    tenant: "eu-west",
  },
  telemetry: {
    includeRuntimeContext: {
      labels: true,
      thread_id: true,
      user_id: true,
      tenant: true,
    },
  },
});
```

Only keys marked `true` in `includeRuntimeContext` are sent. Each one arrives on the
span as `ai.settings.context.<key>`, and nested objects are flattened into dotted
keys such as `ai.settings.context.a.b`.

### AI SDK 6 and earlier: experimental_telemetry

```typescript
const response = await generateText({
  model: openai("gpt-5-mini"),
  prompt: message,
  experimental_telemetry: {
    isEnabled: true,
    metadata: {
      labels: ["checkout", "beta"],
      thread_id: "conversation-8f21",
      user_id: "user-42",
      tenant: "eu-west",
    },
  },
});
```

`experimental_telemetry` is the AI SDK's own experimental API, and its shape
can change between AI SDK versions. It accepts strings, numbers, booleans and
arrays of them as metadata values. It does not accept a nested object, so
flatten anything deeper into separate keys.

### Precedence

A `null` inside a `labels` array is dropped. A `thread_id`, `user_id`,
`customer_id` or `metadata.<key>` you also set as a span attribute wins over the
one you pass here. Labels are the exception: the two sets are combined, so the
trace keeps both. See
[Capturing Metadata and Attributes](/integration/typescript/tutorials/capturing-metadata)
for the attribute names.
