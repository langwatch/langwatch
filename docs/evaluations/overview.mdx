An evaluation runs an evaluator on an input and an output and returns a verdict: a pass or fail, a score, a label, and the details behind it. LangWatch runs the same evaluators in three places: on a dataset in the Experiments workbench, on production traces as an online evaluation, and inside your request as a guardrail.

## Which one to use

| Goal | Use |
|------|-----|
| Check a prompt change on a dataset before you deploy it | [Experiments](/evaluations/experiments/overview) |
| Compare two prompts, models or agents on the same rows | [Comparison](/evaluations/experiments/ui/pairwise-compare) |
| Gate a deployment on a pass rate from your pipeline | [Run experiments from CI/CD](/evaluations/experiments/ci-cd) |
| Score production traffic and follow the pass rate over time | [Online Evaluation](/evaluations/online-evaluation/overview) |
| Block a jailbreak or a policy violation before the response is sent | [Guardrails](/evaluations/guardrails/overview) |
| Get a Slack message or an email when a monitor fails | [Online Evaluation](/evaluations/online-evaluation/overview) with [Automations](/features/automations) |
| Score outputs by hand and collect the reviews | [Annotations](/annotations/overview) |

## Start

<Tabs>
  <Tab title="Platform">
    Open [Experiments](https://app.langwatch.ai/@project/experiments), click **New Experiment**, add a dataset, a prompt and an evaluator, then click **Run**. See [Experiments](/evaluations/experiments/overview).
  </Tab>
  <Tab title="Python">
```python
import langwatch

evaluation = langwatch.experiment.init("my-first-experiment")

for idx, row in evaluation.loop(dataset.iterrows()):
    response = my_llm(row["input"])
    evaluation.log("quality", index=idx, score=0.95)
```
  </Tab>
  <Tab title="TypeScript">
```typescript
import { LangWatch } from "langwatch";

const langwatch = new LangWatch();
const evaluation = await langwatch.experiments.init("my-first-experiment");

await evaluation.run(dataset, async ({ item, index }) => {
  const response = await myLLM(item.input);
  evaluation.log("quality", { index, score: 0.95 });
});
```
  </Tab>
</Tabs>

To score production traffic, open [Online Evaluations](https://app.langwatch.ai/@project/online-evaluations), click **New Online Evaluation**, pick an evaluator, set the trace filter and the sampling rate, and save. See [Setting up monitors](/evaluations/online-evaluation/setup-monitors).

To block a response, call the evaluator from your code with `as_guardrail=True` and check `passed` before you answer the user:

```python
import langwatch

@langwatch.trace()
def my_llm_call(user_input):
    guardrail = langwatch.evaluation.evaluate(
        "azure/jailbreak",
        name="Jailbreak Detection",
        as_guardrail=True,
        data={"input": user_input},
    )

    if not guardrail.passed:
        return "I can't help with that request."

    # Continue with the normal call
```

See [Guardrails](/evaluations/guardrails/overview) for the TypeScript call and the error handling.
