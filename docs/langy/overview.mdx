You ask it a question in plain language, wherever your trace and eval data already lives. Langy reads the relevant production traces and evals through the `langwatch` CLI, its only path to your data.

When a question needs a check, it writes a Scenario simulation test or evaluation that captures the problem, drafts a fix, and opens a pull request on the repo you install it on. The Scenario tests it wrote run in your CI, so what comes back is either findings or a PR with green checks.

A human reviews and merges. Langy never merges its own PR.

<Frame caption="The Langy panel open on the LangWatch home. Ask it a question and it starts reading your traces.">
  ![The Langy home with the chat panel open and suggested prompts](/images/langy/overview/chat-panel-empty.png)
</Frame>

Langy runs each conversation in its own isolated sandbox and uses your own model accounts and API keys. Every turn it takes is itself a traced, costed run in your LangWatch project, so you watch Langy work with the same tools you use to watch your own agents.
