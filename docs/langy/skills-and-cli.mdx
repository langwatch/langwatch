Bring whichever coding agent you already use, Claude Code, Codex, Cursor, or opencode itself, and give it the same two pieces Langy runs on: the `langwatch` CLI and Skills. What Langy adds on top of those, so you do not have to assemble it yourself, is covered further down.

<Info>**Pairs with:** [Ask Langy](/langy/chat) (the assembled version), [Governance CLI](/ai-governance/cli) (the CLI namespace), [Skills Directory](/skills/directory) (install Skills into your own agent).</Info>

## The CLI Langy uses is the one you can install

Langy reads and writes LangWatch through the `langwatch` CLI. It has no private LangWatch tool or hidden API for this: it shells the same public CLI you can install from npm.

```bash
npm install -g langwatch
langwatch login
```

From there the same commands Langy runs are yours to run:

```bash
langwatch trace search --origin application
langwatch analytics query --metric <metric>
langwatch scenario create
langwatch scenario run
langwatch experiment run
langwatch monitor create
```

Because the CLI is the substrate, any coding agent that can run a shell command can do what Langy does with your LangWatch data.

## Skills point your agent at the right command

Skills are instruction sets (AgentSkills-style) that teach a coding agent when to reach for which command. Install a Skill into your own agent and it knows how to set up evals, write Scenario tests, and read traces without you spelling out each step.

See the [Skills Directory](/skills/directory) to install them into Claude Code, Codex, Cursor, or another agent.

Langy ships with a native catalog of these Skills baked in. A few of them:

| Skill | What it covers |
|---|---|
| `agent-performance` | Read how an agent is doing across traces and metrics |
| `scenarios` | Write and run Scenario multi-turn simulation tests |
| `evaluations` | Define evaluators and score runs |
| `github` | Open bot-authored pull requests on installed repos |
| `tracing` | Instrument and read traces |

## What Langy adds on top

The CLI and Skills are the parts you can assemble yourself. Langy is the assembled version, so you do not have to build the harness:

- **The harness is built.** The coding agent, the CLI, and the native Skills come pre-wired, with the LangWatch credentials already injected per session.
- **It runs sandboxed.** Each session runs in an isolated per-session sandbox on your own models and accounts. See [Ask Langy](/langy/chat) for how a session works.
- **GitHub is wired.** The `github` skill uses the [GitHub App you install](/langy/pull-requests), so PRs are bot-authored and credited to you out of the box.

If you would rather drive your own agent, the [Skills Directory](/skills/directory) and the [CLI](/ai-governance/cli) are public and yours to use. If you want it assembled and sandboxed, that is Langy.
