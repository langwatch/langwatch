## Intro

Stop a registry agent on every platform it runs on: Databricks serving endpoints, Amazon Bedrock agent aliases and gateway virtual keys. Set each agent's stop plan, request a stop, approve or deny it, read every target's outcome and restore the agent. Needs an organization API key on an Enterprise plan.
