## Intro

Create and manage dashboards and the widgets on them. Each widget holds a LangWatchQL query and a chart setup.

These routes answer from API version `2026-10-26`. A request pinned to an earlier `X-API-Version` gets a 404, so drop the pin or send `2026-10-26`.
