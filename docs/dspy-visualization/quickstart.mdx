## 2. Login to LangWatch

Import and authenticate the LangWatch SDK:

```python
import langwatch

langwatch.login()
```

Be sure to log in or create an account using the displayed link, then provide your API key when prompted. If `LANGWATCH_API_KEY` is already set in the environment, `langwatch.login()` uses it and does not prompt.

## 3. Start tracking

Before your DSPy program compilation starts, initialize langwatch with your experiment name and the optimizer to be tracked:

```python
# Initialize langwatch for this run, to track the optimizer compilation
langwatch.dspy.init(experiment="my-awesome-experiment", optimizer=optimizer)

compiled_rag = optimizer.compile(RAG(), trainset=trainset)
```

A complete run, small enough to try first:

```python
import dspy
import langwatch
from dspy.teleprompt import BootstrapFewShot

dspy.configure(lm=dspy.LM("openai/gpt-5-mini"))

trainset = [
    dspy.Example(question="What is 2 + 2?", answer="4").with_inputs("question"),
    dspy.Example(question="What is the capital of France?", answer="Paris").with_inputs("question"),
]


def exact_match(example, prediction, trace=None):
    return example.answer.lower() == prediction.answer.lower()


optimizer = BootstrapFewShot(metric=exact_match)
langwatch.dspy.init(experiment="my-awesome-experiment", optimizer=optimizer)

compiled = optimizer.compile(dspy.ChainOfThought("question -> answer"), trainset=trainset)
```

`init` tracks `BootstrapFewShot`, `BootstrapFewShotWithRandomSearch`, `COPRO`, `MIPROv2` and `GEPA`, and a `dspy.Evaluate` through the `evaluator` parameter. A GEPA run gets one step for the seed program and one for every candidate evaluated on the validation set, with the candidate's instructions and the score of each validation example. For any other optimizer, see [Custom optimizer tracking](/dspy-visualization/custom-optimizer).
