A dataset is a table of rows your experiments run on. Each column has a name and a type, and each row is one case: an input, the expected output when you have one, and any other field your prompt or evaluator reads.

## Create a dataset

Open [Datasets](https://app.langwatch.ai/@project/datasets) and click **Upload or create dataset**.

<Frame>
<img src="/images/datasets/datasets-list.png" alt="The Datasets list with the Upload or create dataset menu open" />
</Frame>

The menu has two entries:

| Entry | What it does |
|-------|--------------|
| **Upload datasets** | Creates one dataset per file from CSV, JSON or JSONL files. |
| **Create empty dataset** | Opens the **New Dataset** drawer where you name the dataset and define its columns. |

### Create an empty dataset

In the **New Dataset** drawer, type a **Name**; the slug under it is what the SDKs and the CLI use. Then define the **Columns**. A new dataset starts with `trace_id`, `timestamp`, `input`, `output`, `contexts`, `total_cost` and `annotations`. Remove the columns you do not need, click **Add Column** for the ones you do, and click **Create Dataset**. The type select on each column offers `string`, `number`, `boolean`, `date`, `list`, `json`, `image (URL)`, `json chat messages (OpenAI format)` and `json spans`.

<Frame>
<img src="/images/datasets/dataset-new-drawer.png" alt="The New Dataset drawer with the name, its slug, and the default columns with their types" />
</Frame>

Column names must be unique and cannot be `id` or `selected`. Each column has one of these types:

| Type | Holds |
|------|-------|
| `string` | Text. Use it for `input`, `output` and `expected_output`. |
| `number` | A number, for example a cost or a token count. |
| `boolean` | `true` or `false`. |
| `date` | A timestamp. |
| `list` | A list of strings, for example retrieved contexts. |
| `json` | Any JSON value. |
| `image (URL)` | The URL of an image. The grid renders it as a thumbnail. See [Images in datasets](/datasets/dataset-images). |
| `json chat messages (OpenAI format)` | A list of chat messages with `role` and `content`. |
| `json spans` | The spans of a trace, as JSON. |

### Upload files

**Upload datasets** opens a drawer that accepts CSV, JSON and JSONL files, several at a time. Each file becomes one dataset. For each file, edit the dataset name, then check the columns read from the file header: rename a column, change its type, drag it to reorder, or exclude it. Click **Upload all**.

<Frame>
<img src="/images/datasets/dataset-upload-drawer.png" alt="The Upload datasets drawer with a CSV file added and its columns listed" />
</Frame>

A file can be up to 5 GB. A large file shows **Processing** in the list until its rows are stored.

## Edit a dataset

Click a dataset in the list to open its page. The header shows the record count and an autosave status.

| Button | What it does |
|--------|--------------|
| **Download as CSV** | Exports every row. |
| **Add rows** | Opens **Add rows from CSV**. Each dataset column has a **Select column** control that lists the columns of your file and **Set empty**. Map every column, then click **Upload**, which stays disabled until the file is attached. |
| **Edit columns** | Opens the dataset drawer to add, rename, retype or remove columns. |
| **Run experiment** | Opens the Experiments workbench with this dataset loaded. See [Experiments](/evaluations/experiments/overview). |

<Frame>
<img src="/images/datasets/dataset-add-rows-csv.png" alt="The Add rows from CSV modal with a CSV file attached and a Select column control for the input and expected_output columns" />
</Frame>

Click a cell to edit it. **Add row** under the grid appends an empty row. Select rows with the checkboxes and click **Delete** to remove them. Every change saves as you make it.

The row menu in the datasets list has **Replicate to another project**, **Edit dataset** and **Delete dataset**. A deleted dataset can be restored from the toast for 10 seconds.

## Add rows from traces

Open the [Trace Explorer](https://app.langwatch.ai/@project/traces), select the traces with the checkboxes, and click **Add to dataset** in the action bar. From an open trace, the header menu has **Add trace to dataset** and, for a multi-turn conversation, **Add conversation to dataset**.

<Frame>
<img src="/images/datasets/trace-explorer-add-to-dataset.png" alt="The Trace Explorer with three traces selected and the action bar: Export selected, Add to context, Add to annotation queue and Add to dataset" />
</Frame>

The **Add to Dataset** drawer has three parts:

1. **Dataset**: pick an existing dataset, or click **+ Create New**.
2. **Mapping**: one source per dataset column. **Current Trace** maps each trace to one row. **Thread** groups the selected traces by `thread_id` and maps each conversation to one row. See [Threads in datasets](/datasets/dataset-threads).
3. **Preview**: the rows that will be added. Double-click a cell to edit it, and untick a row to leave it out.

<Frame>
<img src="/images/datasets/add-to-dataset-drawer.png" alt="The Add to Dataset drawer with the Current Trace mapping of input and output onto the dataset columns and the three preview rows that will be added" />
</Frame>

Click **Add N rows to dataset**. LangWatch remembers the mapping per dataset, so the next time you add traces to it the mapping is already set.

The sources a column can map to are the trace fields: `trace_id`, `thread_id`, `timestamp`, `input`, `output`, `contexts`, the `metrics` (cost, tokens, timings), `spans`, `metadata` keys, `evaluations` per evaluator, `annotations` (comment, score, reason, expected output), `events`, and **Full Trace (AI-Readable)**, a text rendering of the whole trace for an LLM to read. When a column name matches a source, for example `input` or `output`, the mapping is filled in for you.

To keep adding matching traces as they arrive, use an automation. See [Build datasets from traces automatically](/datasets/automatically-from-traces).

## Manage datasets from code

The Python and TypeScript SDKs, the CLI, the MCP server and the REST API list, create, read and update datasets and their rows. See [Programmatic access](/datasets/programmatic-access).

**Also check:** [Experiments](/evaluations/experiments/overview) to run a dataset through your prompts and score every row, and [Annotations](/annotations/queues) to send reviewed traces to a dataset at the end of a review session.
