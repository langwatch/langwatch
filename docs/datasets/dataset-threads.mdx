---
title: Threads in datasets
description: Add whole conversations to a dataset, one row per thread, with every trace of the thread in one column.
---

A thread is the set of traces that share a `thread_id` in their metadata: one conversation, one row. Use it when the evaluation needs the whole conversation, for example to check whether the user's problem was resolved by the end.

## Add threads to a dataset

<Steps>
<Step title="Give the dataset a column for the traces">
Open the dataset, click **Edit columns**, and add a column of type `json`, for example `traces`. Keep a `string` column for `thread_id` if you want it in the row.
</Step>

<Step title="Select the traces">
Open the [Trace Explorer](https://app.langwatch.ai/@project/traces), select traces from the conversations you want, and click **Add to dataset**. You do not need to select every trace of a conversation; LangWatch pulls the rest of each thread in the next step.
</Step>

<Step title="Switch the mapping to Thread">
In the **Add to Dataset** drawer, click **Thread** under **Mapping**. A badge shows how many traces the selected threads hold. Map the `traces` column to the **traces** source and pick the fields to keep per trace; **input** and **output** are selected by default. Map `thread_id` to **thread_id**. The **traces** source also fits a `string` column, which then holds the JSON list as text.

<Frame>
<img src="/images/datasets/add-to-dataset-thread.png" alt="The Add to Dataset drawer with the mapping on Thread, the 4 traces badge, the traces source keeping input and output per trace, and Full Thread (AI-Readable) mapped onto a second column" />
</Frame>
</Step>

<Step title="Add the rows">
Check the **Preview**, then click **Add N rows to dataset**. Each row is one thread; the `traces` cell is a JSON list with one object per trace.
</Step>
</Steps>

A source named **Full Thread (AI-Readable)** is also available. It renders the whole conversation as text for an LLM judge to read.

Traces without a `thread_id` are grouped into one row named `no_thread`.
