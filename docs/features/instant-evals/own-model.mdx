## LangWatch Instant Preview or your own model

By default Instant Evals are answered by **LangWatch Instant Preview**, the decision model LangWatch hosts and bills as described in [Limits and cost](/features/instant-evals/limits-and-cost). You can pick a decision model on your own provider account instead, per organization, team or project. The provider then bills your account for every row judged, and LangWatch charges nothing for those rows.

## The models you can pick

| Model in the picker               | Provider to add       | What the provider needs                                                       |
| --------------------------------- | --------------------- | ----------------------------------------------------------------------------- |
| OpenAI Decisions API              | OpenAI                | API key. Runs `gpt-6-luna`                                                    |
| Azure OpenAI Decisions API        | Azure OpenAI          | API key, endpoint and a `gpt-6-luna` deployment on your resource. See [Azure](#azure) |
| Microsoft Decision 1 (Azure)      | Azure OpenAI          | API key, endpoint and a Microsoft Decision 1 deployment on Azure AI Foundry. See [Azure](#azure) |
| Inception Mercury Decide          | Inception             | API key                                                                       |
| Perplexity Decider v1.2           | Perplexity            | API key                                                                       |
| Perplexity Decider Flash v1.2     | Perplexity            | API key                                                                       |
| Cloudflare Clef                   | Cloudflare Workers AI | Account id and API token                                                      |
| Cloudflare Clef Flash             | Cloudflare Workers AI | Account id and API token                                                      |
| TypeSafe Jev 1.14                 | TypeSafe              | API key                                                                       |
| Jev 1.14 (OpenRouter)             | OpenRouter            | API key                                                                       |
| Microsoft Decision 1 (OpenRouter) | OpenRouter            | API key                                                                       |
| Liquid d1.1 (OpenRouter)          | OpenRouter            | API key                                                                       |
| Fireworks Rune                    | Fireworks             | API key                                                                       |

Each model runs only on the model it names. Picking OpenAI Decisions API or Azure OpenAI Decisions API needs `gpt-6-luna` on that account; the other rows need nothing from OpenAI.

## Set it up

<Steps>
  <Step title="Add the provider">
    At **Settings > Model Providers**, click **Add Model Provider**, choose the provider from the table above and enter its key. Scope it to every organization, team or project that should run on it. See [Model Providers](/platform/model-providers) for the drawer.
  </Step>
  <Step title="Pick the model">
    In **Default Models** on the same page, click **Add config**, or the edit button of an existing config, and pick its scopes. The **Instant Evals** column offers LangWatch Instant Preview and every decision model that each picked scope holds an enabled key for. Pick yours and save.
  </Step>
  <Step title="Run">
    Start a run as usual. The pick applies within five seconds, to the next rows judged.
  </Step>
</Steps>

A model is offered only when every scope of the config can run it. A config on the organization is offered only the keys saved on the organization, not a key one project holds, and a config on two projects only what both hold. A save that names a model one of its scopes cannot run is refused.

A project config beats a team config, which beats an organization config, as for the other [default models](/platform/model-providers#default-models). For the provider row, a key saved on the project beats one saved on its team or organization.

## Azure

Both Azure models run on the Azure OpenAI provider row: its **API Key**, and its **Endpoint** to find your resource.

- **Endpoint** is the URL of your resource, such as `https://my-resource.openai.azure.com`. LangWatch reads only the resource name from it and calls `https://my-resource.openai.azure.com/openai/v1/decisions` for Azure OpenAI Decisions API, and `https://my-resource.services.ai.azure.com/providers/microsoft/v1/systemone` for Microsoft Decision 1. An endpoint on `openai.azure.com`, `cognitiveservices.azure.com` or `services.ai.azure.com` works. Any other host, `http`, a custom port, or an Azure API Management gateway does not, so the key never goes outside Azure.
- **Decisions Deployment** is the name of your `gpt-6-luna` deployment. Leave it empty if the deployment is named `gpt-6-luna`.
- **Microsoft Decision 1 Deployment** is the name of your Microsoft Decision 1 deployment on Azure AI Foundry. Leave it empty if it keeps the model's name.

Keep **Use API Gateway** off: the key, the endpoint and both deployment fields show only then, and a gateway row has no Azure endpoint to call, so every row would be skipped as `classifier_key_invalid`. The key travels in the `api-key` header.

Deploy the model on the resource before you pick it. In the Azure portal or Azure AI Foundry, open the resource, add a deployment of `gpt-6-luna` (or Microsoft Decision 1), and note its name. With the Azure CLI:

```bash
az cognitiveservices account deployment create \
  --resource-group my-group --name my-resource \
  --deployment-name gpt-6-luna --model-name gpt-6-luna --model-format OpenAI --model-version 2026-09-22 \
  --sku-name GlobalStandard --sku-capacity 50
```

Without the deployment, every row is skipped as `classifier_not_configured`, as below.

## When your model cannot answer

A run on your own model never falls back to LangWatch Instant Preview. The rows it cannot judge are written as `skipped`, with the reason in `error`, and the run goes on. Read them with `langwatch instant-eval results <run-id> --status skipped`.

| `error`                           | Why                                                                                                         | Fix                                                                         |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `classifier_key_invalid`          | The provider refused the key (401, 402 or 403), or the scope has no enabled provider row, no key, or an endpoint outside Azure | Check the row and its key at **Settings > Model Providers**                 |
| `classifier_not_configured`       | The provider answered 404: the account does not hold the model, or the Azure deployment does not exist      | Deploy the model, or set the deployment name on the Azure row               |
| `classifier_rate_limited`         | The provider answered 429 on every retry                                                                    | Raise the rate limit or quota on your provider account                     |
| `classifier_provider_unavailable` | The provider answered 5xx on every retry                                                                    | Try again later                                                             |

A refused key and a missing model are not retried. A rate limit and an outage are retried before the row is skipped.

## What changes on your own model

- **Cost.** The provider bills your account. LangWatch charges nothing for the rows and the [free budget](/features/instant-evals/limits-and-cost#the-free-budget) does not apply.
- **Limits.** The row, question and text limits in [Limits and cost](/features/instant-evals/limits-and-cost#limits) still apply.
- **Where the judged text goes.** The text of each row and your questions go straight to your provider, under your own agreement with it, instead of to LangWatch's judge.
- **The search bar.** The search bar still runs on LangWatch Instant Preview.
