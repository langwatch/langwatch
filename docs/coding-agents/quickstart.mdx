Run your agent through the LangWatch wrapper. The first run opens a browser sign-in, asks one question about billing, and starts the agent; every run after that just starts the agent.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    npx langwatch claude
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    npx langwatch codex
    ```
  </Tab>
  <Tab title="GitHub Copilot">
    ```bash
    npx langwatch copilot
    ```
  </Tab>
  <Tab title="Gemini CLI">
    ```bash
    npx langwatch gemini
    ```
  </Tab>
  <Tab title="opencode">
    ```bash
    npx langwatch opencode
    ```
  </Tab>
  <Tab title="Cursor">
    Cursor routes through the LangWatch AI Gateway rather than a telemetry wrapper. See [Cursor on the gateway](/ai-gateway/cli/cursor).
  </Tab>
</Tabs>

The billing question is "Using a subscription" against "Using an API key". Pick your subscription to keep your own plan and login, with LangWatch receiving telemetry only. Pick an API key to route the model calls through the LangWatch AI Gateway under your organization's budgets and policies. LangWatch remembers your answer.

The wrapper changes nothing else: same flags, same subcommands, same exit code as the bare tool.

## What you see now

Work with the agent for a minute, then open [/me](https://app.langwatch.ai/me):

- Your session is on the [sessions list](/coding-agents/sessions), with its cost, the context it carried, and a terminal replay of the conversation.
- Your spend for the month is on the usage cards. See [Usage analytics](/coding-agents/usage-analytics).
- Once the session works on a branch with a pull request, it shows under [Pull requests](/coding-agents/pull-requests).

## Expand from here

- **Make plain runs report too.** `langwatch instrument <tool>` writes the connection persistently and exits, so `claude` without the wrapper reports as well. Each agent's page covers it, for example [Claude Code](/coding-agents/claude-code).
- **Send a machine's telemetry to a team project** with `--project`, or wire servers and CI with an ingest key and no login. See [Team projects](/coding-agents/team-projects) and [Headless machines and CI](/coding-agents/headless-and-ci).
- **Route the model calls through the LangWatch AI Gateway** for budgets, model policies and provider fallback on top of the telemetry. See the [coding CLI gateway integrations](/ai-gateway/cli/overview).
- **Worried who sees what you type?** [Privacy](/coding-agents/privacy) states the boundaries exactly.
