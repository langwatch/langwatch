Run your agent through the LangWatch wrapper: the agent starts as usual, and its sessions report to LangWatch. The first run opens a browser sign-in and asks one question before the agent starts.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    npx langwatch claude
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    npx langwatch codex
    ```
  </Tab>
  <Tab title="GitHub Copilot">
    ```bash
    npx langwatch copilot
    ```
  </Tab>
  <Tab title="Gemini CLI">
    ```bash
    npx langwatch gemini
    ```
  </Tab>
  <Tab title="opencode">
    ```bash
    npx langwatch opencode
    ```
  </Tab>
  <Tab title="Cursor">
    Cursor routes through the LangWatch AI Gateway rather than a telemetry wrapper. See [Cursor on the gateway](/ai-gateway/cli/cursor).
  </Tab>
</Tabs>

The question asks how to connect. **Using a subscription**, the first answer, keeps your own plan and your own login, and LangWatch receives telemetry only. **Using an API key** routes the model calls through the LangWatch AI Gateway under your organization's budgets and policies. On a subscription plan, take the first answer. LangWatch remembers the answer per tool, and each agent's page covers the question in full, for example [Claude Code](/coding-agents/claude-code#run-claude-code-through-the-wrapper).

You may not see the question at all: when your organization allows one path only, LangWatch takes that path without asking, and a run with no terminal attached keeps your own plan. `--tool-mode` sets it explicitly on any run.

## What you see now

Work with the agent for a minute, then open [/me](https://app.langwatch.ai/me):

<Frame caption="The sessions list on /me. Each row is one session, with its cost, the context it carried, and the pull requests it drove.">
  ![Sessions list](/images/coding-agents/sessions-list.png)
</Frame>

- Your session is on the [sessions list](/coding-agents/sessions), with its cost, the context it carried, and a terminal replay of the conversation. The [data privacy policy](/coding-agents/privacy) can drop content; the session then shows its numbers without the conversation.
- Your spend for the month is on the usage cards. See [Usage analytics](/coding-agents/usage-analytics).
- Once the session works on a branch with a pull request, it shows under [Pull requests](/coding-agents/pull-requests).

## Expand from here

- **Make plain runs report too.** `langwatch instrument <tool>` writes the connection persistently and exits, so `claude` without the wrapper reports as well. Each agent's page covers it, for example [Claude Code](/coding-agents/claude-code).
- **Send a machine's telemetry to a team project** with `--project`, or wire servers and CI with an ingest key and no login. See [Team projects](/coding-agents/team-projects) and [Headless machines and CI](/coding-agents/headless-and-ci).
- **Route the model calls through the LangWatch AI Gateway** for budgets, model policies and provider fallback on top of the telemetry. See the [coding CLI gateway integrations](/ai-gateway/cli/overview).
- **Worried who sees what you type?** [Privacy](/coding-agents/privacy) states the boundaries exactly.
