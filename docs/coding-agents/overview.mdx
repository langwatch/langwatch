One command connects an agent. After that, LangWatch records every session with its cost, its context economics, its conversation, and the pull requests it drove. An organization that drops or restricts content in its [data privacy policy](/coding-agents/privacy) keeps the numbers and loses the conversation.

```bash
npx langwatch claude
```
