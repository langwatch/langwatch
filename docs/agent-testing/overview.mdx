## How a test runs

Three parties take part in every test. Your agent answers as it does in production. A simulated user plays the situation the scenario describes, turn by turn, with different words on every run. A judge model reads the whole conversation and the agent's own traces, and decides each criterion.

A scenario is the unit of testing: one situation and the criteria the conversation must meet. Test suites group scenarios, run plans keep the history of every run, and the Results tab shows the pass rate over time. Every part has its own page below.

## Two ways to run

Both ways use the same simulated user, the same judge and the same results pages. They differ in where the scenarios are written and who runs them.

## Agent testing and dataset evaluation

A dataset evaluation scores one input against one expected output. An agent is a process: it holds state, calls tools and takes several turns to reach an outcome, so a single input-output pair cannot describe what it must do in the middle of a conversation.

For example, an evaluation dataset holds rows like these:

| query                            | expected_answer                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| What is your refund policy?      | We offer a 30-day money-back guarantee on all purchases.                                                     |
| How do I cancel my subscription? | You can cancel your subscription by logging into your account and clicking the "Cancel Subscription" button. |

A scenario describes the whole conversation and checks the steps between the turns:

```python
script=[
  scenario.user("hey I have a problem with my order"),
  scenario.agent(),
  expect_ticket_created(),
  expect_ticket_label("ecommerce"),
  scenario.user("i want a refund!"),
  scenario.agent(),
  expect_tool_call("search_policy"),
  scenario.user("this is ridiculous! let me talk to a human being"),
  scenario.agent(),
  expect_tool_call("escalate_to_human"),
]
```

Keep both. Use evaluations for the parts inside the agent, such as one retrieval step or one prompt, where you optimize a metric on many examples. Use scenarios to prove the agent behaves correctly end to end, to reproduce an incident from production, and to catch a regression before a release.
