# API framework bypasses: middleware, facts and handlers doing the door's work

Date: 2026-10-05. Branch: feat/strict-feature-layout-v0. Status: findings; nothing fixed yet.
Ruling: `.claude/coordinator/rulings-2026-10-05.md`. Rule: CLAUDE.md rule 6, ARCHITECTURE.md §8.

## What the framework already does (`packages/api/src`)

- Pipeline (`rest/runtime.ts:482-560`): door, credential facts, body cap, raw body, validators and parsed input, input-reading authorisation, handler.
- Body: validators at `runtime.ts:747` (unparseable 400 `malformed_request`, schema failure 422); an absent body is `{}` (`runtime.ts:810-858`). `withInput` `declaration.ts:675`, `withRawBody` `:705`, `withMultipart` `:737`, `withBodyLimit` `:1221`, `withHeaders` `:1240`.
- Authentication: door kinds `access/access.ts:81-90`, `withCredential` `declaration.ts:1270`; escape kinds `publicRoute`, `anyAuthenticated`, `optionalCredential`, `deferredScope` at `access.ts:130-195`; the door is `modules/auth/process/src/services/api-door.service.ts`.
- Permission: REST `withPermission` `declaration.ts:905` (one permission; `{at:"route"|"grants"|"organization"}`), checked `runtime.ts:1518`. tRPC `trpc/runtime.ts:422-485` (one, any, all, `noPermission`, `serviceAuthorized`).
- Also: `withEntitlement` `:825`, `withRateLimit` `:777`, `mintsCredential` `:848`, `withIdempotency` `:866`, protocol refusal `withResponse("protocol",{refusal})` `:1062`, `withMiddleware` `:1250`, error mapping `rest/response.ts:748`.

## Guards so it cannot come back (per the 2026-10-05 ruling, these are the few rules that accept a justified disable)

1. Credential readers (`*CredentialOfRequest`, `browserCallerOfRequest`, `principalOfCredential`, `extractBearer*`) only in `packages/api`, `packages/process`, `modules/auth`.
2. No auth-header reads (`authorization`, `x-auth-token`, `x-api-key`, `x-project-id`) in transport, app or `*.module.ts` files.
3. `withRawBody` takes a required `because`; `JSON.parse` of a raw body or input field in a transport is an error; no `hono/http-exception` in modules.
4. Escape-kind declarations (`publicRoute`, `anyAuthenticated`, `deferredScope`, `optionalCredential`, `noPermission`, `serviceAuthorized`) are flagged; a handler that pairs `admitX` with an operation is caught.
