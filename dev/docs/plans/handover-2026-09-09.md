## The final shape (what "done" looks like)

```
packages/features/<module>/            (folder still named features until D-a lands; the word is "module")
  contract/src/  <m>.api.ts (interface <M>Api + featureApi token)  <m>.trpc.ts (defineTrpcContract)
                 schemas, errors (HandledError subclasses with codes), no abstract service
  server/src/    <m>.server.ts = defineFeature(<m>).withRepositories(registry).withApp(App).withTransports(...).build()
                 app/<m>.app.ts (one class implements <M>Api; static dependencies name peer APIs)
                 services/ (private), rules/, ports/ (genuinely external: eventing, metrics, HTTP, flags)
                 repositories/{<x>.repository.ts, prisma/, memory/, <m>-repositories.registry.ts}  (twins under one contract test)
                 transport/<m>.trpc.ts, <m>.rest.ts (flat declarations on @langwatch/api; never mounted here)
  web/src/       model/ behavior/ ui/{elements,blocks,sections}  flat entry files src/<id>.ts
apps/api/src/features/<m>/   <m>.composition.ts (installApi<M> boots createApp...withFeature), <m>-{trpc,rest}.mount.ts
apps/worker, apps/tasks      boot the same installer with their own infrastructure
packages/api/                the one runtime: rest/{declaration?,runtime,addressing?,request,idempotency?,credential,response,openapi,security}, trpc/{runtime,policy,audit}
```

Rules that hold everywhere: one runtime per transport; annotation is the reference module; no refusing twins (a process
installs a module or does not); no `try*` (nullable only on `find*`); config schema-driven, `process.env` only at boot;
ksuid ids; `{ ok, error }` results banned; folders of at most 12 files, no fragments under 20 lines; baselines only shrink
and share one shape; every scenario bound by `@scenario`.
