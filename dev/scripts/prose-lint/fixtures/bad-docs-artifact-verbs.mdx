## Reading the failure

A failing scenario names the broken behavior, and the trace names the layer that broke it. Follow your harness. It injects its own tool map with schemas, so a hand-written map in your prompt competes with it.

An image rides an `image_url` part carrying a data URL, and the chip in the trace list carries the filename so the reader knows which file was sent.
