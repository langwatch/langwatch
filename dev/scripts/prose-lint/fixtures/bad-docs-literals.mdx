# Instant Evals

## Where does the judged text come from?

Instant Evals are behind the `release_instant_evals_enabled` feature flag; ask LangWatch to turn it on for your project. It matters because the AI gateway records the tokens each run sends, and the langwatch dashboard shows the total. We dogfood every run in this PR before shipping it, so the numbers on the page come from our own project rather than from a customer's, which is also why the examples use our internal trace names throughout the guide, and why the token counts you see here differ from the ones a fresh project would show after its first week of traffic once the rows have all been judged and the judgements written back to the results table where the CLI reads them from.
