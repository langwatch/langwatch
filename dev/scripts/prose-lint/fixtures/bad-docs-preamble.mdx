## Introduction

In this guide we will explore the concepts behind Instant Evals and learn how they fit into the LangWatch evaluation story. Learn how to ask questions of your production traces using the LangWatch CLI.

An Instant Eval run judges every trace in a time window against a question you write. Run `langwatch instant-eval run "the customer sounds annoyed" --last 7d` to start one.
