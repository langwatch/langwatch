## Rulings, 2026-10-05 (Alex)

- **Drift is caught by lint, and the message is a prompt.** Wherever code drifts from the architecture direction (middleware doing what the API framework does, such as auth or JSON body parsing; routes opened to any authenticated or unauthenticated caller), a lint rule catches it. The error explains, written to the agent reading it, why the shape is wrong and what to use instead.
- **Drift needs a justified disable.** An agent that still needs the drifting shape adds a disable directive explaining why it cannot use the framework. A bare disable is itself an error.
- **When unsure, ask the human.** A message tells the agent that if the case is confusing, it stops and asks the human rather than disabling.
- **Applies to every area** where code drifts from solid architecture direction, not only transports.
- **Peer-cycle edges:** ask Alex before cutting or listing any of them.
- **Landing:** reviewed slices are committed and pushed directly to feat/strict-feature-layout-v0. First goal: get the branch's CI green.
