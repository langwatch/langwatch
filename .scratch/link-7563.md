Recording the ruling behind this PR's "confirm before every delete" framing, so the title isn't read as blunt fiat:

The rule is **confirm before delete unless the user can restore it themselves.** We enumerated Langy's 15 delete commands and checked each for a user-visible restore path — **none has one.** The only two restorable resources (prompts, experiments) have no delete command. So the exemption is real as a principle but empty in practice, and the behavior lands on: **all 15 confirm.** The carve-out stays in the wording so a future restorable-and-deletable resource qualifies automatically.

This PR carries the prompt/skill/test changes. The **structural gate** (delete unavailable unless the prior turn was Langy-asks + user-says-yes; no self-authored passphrase) is the core fix and is tracked against #7608 / #7562.
