# Modules

One feature per directory. Other code sees a module's contract and calls its `*Api` token; nothing else crosses the line ([ARCHITECTURE.md §3](../dev/docs/ARCHITECTURE.md)). The map of subject to owner is `modules/catalogue.json`; Enterprise modules are indexed in [enterprise/modules](../enterprise/modules/README.md).
