# @langwatch/staff-access-contract

The contract of [staff-access](../README.md): the `staffAccess` tRPC procedures the operator pages call, the `/api/staff-access` wire the `langwatch` CLI reads, the refusals both answer, and the `StaffAccessApi` token. See [ADR-192](../../../dev/docs/adr/192-ops-agent-access.md).
